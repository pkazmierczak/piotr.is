I've been trying to hone some web-development skills the last few days, and yesterday evening I read about a particularly elegant Python microframework called [Flask](http://flask.pocoo.org/). I read the tutorial, did some stackoverflow searches and hacked a very simple (borderline trivial, actually) [app](https://github.com/pkazmierczak/letterpresscheater) for cheating in [LetterPress](http://www.atebits.com/letterpress/) in just a few hours. The code that runs the whole application is merely 50 lines long, and that's only because I'm adhering to [PEP8](https://www.python.org/dev/peps/pep-0008/#blank-lines)’s blank lines policies. Karolina contributed some CSS code and a logo, and we deployed it to [Heroku](http://heroku.com) in a couple of minutes. As a web-development newbie I have to say I'm amazed by how quickly and easily one can learn writing simple applications from scratch these days. And Heroku deployment can be done (for free!) by just one `git push`. Amazing stuff, especially if you remember coding PHP in 2004.
